# Offline icon embeddings

Model: [Xenova/all-MiniLM-L6-v2](https://huggingface.co/Xenova/all-MiniLM-L6-v2/tree/751bff37182d3f1213fa05d7196b954e230abad9), revision `751bff37182d3f1213fa05d7196b954e230abad9`.
Base model: [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2), Apache-2.0. ONNX quantized conversion by Xenova. Model and tokenizer files are distributed here unmodified; icon vectors are generated by EasyDraw.

- Quantized model: 22,972,370 bytes (~23 MB).
- Index: 1,690 × 384 float32, 2,595,840 bytes (~2.6 MB).
- Includes tokenizer files; inference library/platform binaries add further size.
- English descriptions only; screenshots are described in English by the calling AI. This model does not encode pixels.
- Masked mean pooling, L2 normalization, cosine top1, no threshold or reranking.

Run `npm run icons:index` after changing icon names or tags. The generator uses only the bundled model, with no downloads or Python dependency. The index fingerprints ordered IDs, names and indexed English tags. Incompatible catalogs fail explicitly instead of silently assigning mismatched IDs.
